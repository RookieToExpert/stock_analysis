# AI 使用规则

规则回测以 `docs/STRATEGY_SPEC.md` 为准。AI 只作研究助手，不直接决定买卖。

## 不允许

- 告诉 AI 股票后来涨了，再问“当时为什么该买”。
- 用今天的数据评估过去。
- 只展示成功案例。
- 把 AI 对历史事件的解释当作模型有效的证据。

## 向前记录

历史盲测无法排除模型记得结局，所以事件复核采用向前记录。

每次复核都在 `journal/` 写下：

- 日期、价格和可用数据来源
- 事件类型：短期、结构性或诚信
- 判断理由
- 能证明判断错误的信号
- 复核截止日和后续动作

记录提交到 Git 后不改写结论；后续只追加结果。满 1 年、3 年时分别复盘，失败案例也要保留。
