# AI 使用规则

规则回测以 `docs/STRATEGY_SPEC.md` 为准。AI 只作研究助手，不直接决定买卖。

**禁止用已知结局向 AI 索取买入理由。历史验证必须只使用评价日当时可知的信息。**

## 允许和禁止

| 允许 | 禁止 |
|---|---|
| 汇总公告和财报 | 根据后来涨跌解释当时该不该买 |
| 按固定清单做事件分类 | 用今天的数据评估过去 |
| 找反方证据和待核查项 | 只展示成功案例 |
| 写向前记录 | 把 AI 的解释当作模型有效的证据 |
| 协助检查规则实现 | 让 AI 直接下单或覆盖已冻结规则 |

## 信息包

**可以包含：** 评价日、股票代码或匿名编号、已公告财报、公告日、当时价格和估值、当时可知事件、同行当时数据。

**必须删除：** 评价日后的财报、价格、新闻、研报，以及“后来证明”“最终反弹”这类表述。

输出只保留：

- 事件类型：短期、结构性、诚信或数据不足
- 依据和反方证据
- 能证明判断错误的信号
- 复核截止日

## 向前记录

历史盲测无法排除模型记得结局，所以事件复核主要采用向前记录。

- 每次复核写入 `journal/`，使用 `journal/TEMPLATE.md`。
- 记录提交到 Git 后不改写结论，后续只追加结果。
- Git 提交时间作为事前记录时间。
- 满 1 年、3 年时分别复盘，失败案例也保留。

## 历史盲测

只有历史时点数据通过 `docs/STRATEGY_SPEC.md` 的数据门槛后才能做。

- 评价日必须是交易日，且晚于公告可交易时间。不能使用 2022-04-30：它是周六。
- 20 只股票只能检查流程，不能验证模型。
- 规则验证使用完整股票池和多个评价日。
- 盲测标签在打开结果前冻结。
- 规则结论和 AI 结论不一致时，以可复算的规则为准。

数据不足时，结论写“尚不能验证”。

## 外部案例分层

| 类型 | 内容 | 处理 |
|---|---|---|
| 已核到来源 | [大模型前视偏差研究](https://arxiv.org/html/2512.23847v1)：测试显示记忆效应会影响预测结果 | 可以作为风险依据 |
| 已核到部分事实 | [GPT Portfolio 实盘报道](https://www.marketscreener.com/news/can-chatgpt-and-grok-beat-the-market-ce7e5cdfd081fe24)：确有实盘项目，但这次没有核到完整累计收益 | 不能作为 AI 炒股有效的证据 |
| 未核实 | 聚宽 AI 策略打开防未来函数后由盈转亏的具体案例 | 不写成事实，只保留“未来函数会让回测失真”的通用风险 |
| 不足以判断 | [MoSAIC](https://www.mosaicbenchmark.com/)：公开页面显示 2 个月、69 笔交易 | 只借鉴向前公开记录 |

## 红旗

- 只展示赢家，没有失败样本
- 说不清策略、评价日和成交方式
- 收益集中在一两只热门股票
- 没有基准、成本或样本外结果
- 用当前数据解释过去
