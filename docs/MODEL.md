# 长期选股标准 v0.3

适用范围：A 股非金融公司，计划持有 3 年以上。**这套标准还没有回测，分数只用于缩小研究范围，不能直接作为买入信号。**

## 决策流程

1. **排雷**：命中否决项直接出局。
2. **打分**：用 5 年数据判断公司底子，满分 100。
3. **看近期状态**：判断公司是否正在恶化，或股价是否大跌。
4. **事件复核**：判断下跌原因是不是短期的。
5. **分批买入**：写下买入理由和卖出条件，再用真钱。

## 1. 排雷

**自动否决**
- ST 或退市风险
- 金融股（银行、保险、证券等需单独建模）
- 近 3 年或最近 12 个月亏损
- 5 年累计归母净利润非正
- 5 年累计经营现金流 / 合并净利润 < 0.6
- 商誉 / 净资产 > 30%

**数据不足**

缺少连续 5 年年报、核心财务字段、最新资产负债表或 TTM 利润的公司，单列为“数据不足”，不进入名单。未知值用 `None` 表示，不能按 0 处理。资产负债表存在时，未列示的借款和商誉按 0 处理。

**人工核查（当前数据不能自动判断，每只公司默认标记“未查”）**
- 审计意见不是标准无保留
- 被立案调查、财务重述
- 大股东高比例质押或持续减持
- 资金占用、违规担保
- 存贷双高：现金和有息负债都超过总资产 20%，要解释原因

## 2. 打分（100 分）

| 维度 | 指标 | 给分 |
|---|---|---|
| **质量 30** | 5 年 ROE 中位数 | ≥15%：12；≥12%：8；≥8%：4 |
| | 5 年 ROE 最低值 ≥8% | 4 |
| | 5 年毛利率极差 ≤8pp | 4 |
| | 5 年经营现金流 / 合并净利润 | ≥1：7；≥0.8：4 |
| | 4 年营收复合增速 ≥8% | 3 |
| **估值 30** | 盈利收益率：TTM 扣非利润 / 市值 | ≥8%：12；≥6%：8；≥4%：4 |
| | FCF 收益率：5 年平均 FCF / 市值 | ≥6%：12；≥4%：8；≥2%：4 |
| | 可持续股息率 | ≥4%：6；≥2.5%：3 |
| **股东回报 20** | 近 5 年每年都有现金分红支出 | 8 |
| | 5 年分红 / 净利润 | 30%～100%：7；其他 ≥10%：3 |
| | 5 年分红 ≥ 5 年股权融资 | 5 |
| **财务安全 20** | 资产负债率 | ≤40%：7；≤60%：4 |
| | 现金 ≥ 有息负债 | 7 |
| | 商誉 / 净资产 ≤10% | 6 |

- **FCF** = 经营现金流 − 购建长期资产支出。
- **分红**使用已实施的普通股现金分红，按除息年份汇总；不使用现金流表中混有利息和少数股东分红的字段。
- **可持续股息率**取 5 年平均实付分红、5 年平均 FCF、TTM 扣非利润三者的最低值，再除以市值。这是保守约束，不做利润恢复假设。
- **5 年平均盈利收益率**只作报告参考，不计分，用来观察利润下滑时的正常化估值。

## 3. 近期状态

分数主要看历史，看不到当下恶化，所以单独判断。满足任一项就要做事件复核：

- 最新累计扣非利润同比下降 ≥20%
- 最新累计毛利率同比下降 ≥3pp
- 股价较 3 年前复权高点回撤 ≥30%

分数档、近期状态和人工警示分开输出：

| 分数档 | 条件 |
|---|---|
| **合格** | ≥75 分 |
| **观察** | 60～74 分 |
| **放弃** | <60 分 |
| **数据不足** | 核心数据缺失 |
| **出局** | 命中否决项 |

合格公司的下一步：

| 情况 | 动作 |
|---|---|
| 近期恶化或股价大跌 | **事件复核** |
| 状态数据未知，或有存贷双高等警示 | **人工补查** |
| 状态正常 | **人工排雷** |

## 名单分层

**主名单：稳健分红蓝筹。** 必须同时满足：
- 分数档为合格
- 市值 ≥200 亿
- 最近 5 年每年都有现金分红
- 5 年分红率 30%～80%
- 36 个月波动率不属于蓝筹池最高的 30%

**副名单：其他好公司。** 分数档合格但不满足主名单条件，包括小公司和成长型公司。这部分只研究，不作为主要买入来源。

## 4. 事件复核

这一步来自朋友的方法：**好公司因短期利空被低估时买入**。这个思路有道理，但要先证明利空确实是短期的。

| 类型 | 例子 | 处理 |
|---|---|---|
| **短期** | 原料涨价、一次性罚款、行业周期低点、可修复的事故 | 可以继续研究 |
| **结构性** | 需求消失、份额流失、技术替代、政策长期变化 | 下调长期盈利，通常不买 |
| **诚信** | 财务造假、资金占用、隐瞒重大问题、严重产品安全事件 | 一票否决 |

必须能回答这五个问题：

1. 利润下降的原因是什么，公司、研报和数据能否互相印证？
2. 这个因素消失后，毛利率和利润能恢复到哪里？
3. 恢复需要几年，什么数据能证明正在恢复？
4. 同行是否也受影响？只有这家公司变差时更要警惕。
5. 如果利润永远回不到以前，今天的价格还值得买吗？

**红利率要这样看：** 股价大跌会自动抬高股息率。不能看历史股息率，要看“利润和自由现金流支撑得起多少分红”。

## 5. 买入和持有

- 模拟盘按主名单分数从高到低取前 20 只，同分时市值大者优先，等权持有；不足 20 只时留现金。
- 单只股票不超过组合的 10%，单一行业不超过 25%，超限时跳过同业下一只。
- 每半年在年报或半年报披露后调仓一次；涨过上限时在调仓日降回上限。
- 持仓疑点必须写复核截止日；到期查不清的，不加仓，并重新判断是否继续持有。
- 分 2～3 批买入，每批都要有新的基本面证据，不能只因为股价下跌就加仓。
- 每次买入都在 `journal/` 记录理由、预期恢复路径和卖出条件。
- 不设机械止损，也不因短期下跌卖出。
- 逻辑失效、出现诚信问题，或者有明显更好的标的时才卖。
- 每半年和沪深 300 全收益、中证红利全收益比较一次。

## 方法依据

- 质量和估值：Piotroski（2000）、Novy-Marx（2013）、AQR Quality Minus Junk
- 市场过度反应：De Bondt & Thaler（1985）、Lakonishok, Shleifer & Vishny（1994）
- A 股壳价值：Liu, Stambaugh & Yuan（2019）

## 已知局限

- 阈值和权重来自经验，未经回测。
- v0.2 和 v0.3 都看过同一批 15 只试跑结果，这批股票不能作为样本外验证。
- 周期股的 5 年数据可能正好处在高点。
- 质押、减持、审计意见还没有自动化。
- 当前脚本只读取最新数据，不能直接改成历史回测；回测需要历史公告时间、当时可得财报和退市股票全集。
- 通过测试只说明代码按规则运行；模拟盘和样本外回测才用于检验策略。
