# 长期选股标准 v0.2

适用范围：A 股非金融公司，计划持有 3 年以上。**这套标准还没有回测，分数只用于缩小研究范围，不能直接作为买入信号。**

## 决策流程

1. **排雷**：命中否决项直接出局。
2. **打分**：用 5 年数据判断公司底子，满分 100。
3. **看近期状态**：判断公司是否正在恶化，或股价是否大跌。
4. **事件复核**：判断下跌原因是不是短期的。
5. **分批买入**：写下买入理由和卖出条件，再用真钱。

## 1. 排雷

**自动否决**
- ST 或退市风险
- 金融股（银行、保险、证券等需单独建模）
- 年报不足 5 年
- 近 3 年或最近 12 个月亏损
- 5 年累计经营现金流 / 净利润 < 0.6
- 商誉 / 净资产 > 30%

**人工核查（当前数据不能自动判断）**
- 审计意见不是标准无保留
- 被立案调查、财务重述
- 大股东高比例质押或持续减持
- 资金占用、违规担保
- 存贷双高：现金和有息负债都超过总资产 20%，要解释原因

## 2. 打分（100 分）

| 维度 | 指标 | 给分 |
|---|---|---|
| **质量 30** | 5 年 ROE 中位数 | ≥15%：12；≥12%：8；≥8%：4 |
| | 5 年 ROE 最低值 ≥8% | 4 |
| | 5 年毛利率极差 ≤8pp | 4 |
| | 5 年经营现金流 / 净利润 | ≥1：7；≥0.8：4 |
| | 4 年营收复合增速 ≥8% | 3 |
| **估值 30** | 盈利收益率：TTM 扣非利润 / 市值 | ≥8%：12；≥6%：8；≥4%：4 |
| | FCF 收益率：5 年平均 FCF / 市值 | ≥6%：12；≥4%：8；≥2%：4 |
| | 可持续股息率 | ≥4%：6；≥2.5%：3 |
| **股东回报 20** | 近 5 年每年都有现金分红支出 | 8 |
| | 5 年分红 / 净利润 | 30%～100%：7；其他 ≥10%：3 |
| | 5 年分红 ≥ 5 年股权融资 | 5 |
| **财务安全 20** | 资产负债率 | ≤40%：7；≤60%：4 |
| | 现金 ≥ 有息负债 | 7 |
| | 商誉 / 净资产 ≤10% | 6 |

- **FCF** = 经营现金流 − 购建长期资产支出。
- **可持续股息率**取 5 年平均实付分红、5 年平均 FCF、TTM 扣非利润三者的最低值，再除以市值。这样不会被一次超额分红误导。

## 3. 近期状态

分数主要看历史，看不到当下恶化，所以单独判断。满足任一项就要做事件复核：

- 最新累计扣非利润同比下降 ≥20%
- 最新累计毛利率同比下降 ≥3pp
- 股价较 3 年前复权高点回撤 ≥30%

| 结果 | 条件 | 动作 |
|---|---|---|
| **候选** | ≥75 分，状态正常 | 做人工核查，通过后才考虑买 |
| **事件复核** | ≥75 分，触发状态或警示 | 先判断下跌原因 |
| **观察** | 60～74 分 | 记录，不买 |
| **放弃** | <60 分 | 不研究 |
| **出局** | 命中否决项 | 不研究 |

## 4. 事件复核

这一步来自朋友的方法：**好公司因短期利空被低估时买入**。这个思路有道理，但要先证明利空确实是短期的。

| 类型 | 例子 | 处理 |
|---|---|---|
| **短期** | 原料涨价、一次性罚款、行业周期低点、可修复的事故 | 可以继续研究 |
| **结构性** | 需求消失、份额流失、技术替代、政策长期变化 | 下调长期盈利，通常不买 |
| **诚信** | 财务造假、资金占用、隐瞒重大问题、严重产品安全事件 | 一票否决 |

必须能回答这五个问题：

1. 利润下降的原因是什么，公司、研报和数据能否互相印证？
2. 这个因素消失后，毛利率和利润能恢复到哪里？
3. 恢复需要几年，什么数据能证明正在恢复？
4. 同行是否也受影响？只有这家公司变差时更要警惕。
5. 如果利润永远回不到以前，今天的价格还值得买吗？

**红利率要这样看：** 股价大跌会自动抬高股息率。不能看历史股息率，要看“利润和自由现金流支撑得起多少分红”。

## 5. 买入和持有

- 单只股票不超过组合的 10%，单一行业不超过 25%。
- 分 2～3 批买入，每批都要有新的基本面证据，不能只因为股价下跌就加仓。
- 每次买入都在 `journal/` 记录理由、预期恢复路径和卖出条件。
- 不设机械止损，也不因短期下跌卖出。
- 逻辑失效、出现诚信问题，或者有明显更好的标的时才卖。
- 每半年和沪深 300 全收益、中证红利全收益比较一次。

## 方法依据

- 质量和估值：Piotroski（2000）、Novy-Marx（2013）、AQR Quality Minus Junk
- 市场过度反应：De Bondt & Thaler（1985）、Lakonishok, Shleifer & Vishny（1994）
- A 股壳价值：Liu, Stambaugh & Yuan（2019）

## 已知局限

- 阈值和权重来自经验，未经回测。
- 当前只做了 15 只股票的规则试跑，这些股票不是推荐名单。
- 周期股的 5 年数据可能正好处在高点。
- 市值分界、质押、减持、审计意见还没有自动化。
- 免费接口没有退市股票全集，也不足以支持严谨的历史回测。
