# 阅读清单

优先读原文。这里的材料用于理解框架，不是选股依据。

1. Benjamin Graham，《聪明的投资者》：防御型投资者、安全边际
2. [Berkshire Hathaway 股东信](https://www.berkshirehathaway.com/letters/letters.html)：owner earnings、能力圈
3. Lawrence Cunningham 编，*The Essays of Warren Buffett*
4. Robert Hagstrom，*The Warren Buffett Way*
5. Charlie Munger，*Poor Charlie's Almanack*
6. AQR，*Quality Minus Junk*
7. [《Buffett's Alpha》](https://www.aqr.com/insights/research/journal-article/buffetts-alpha)
