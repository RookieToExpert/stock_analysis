## 计算修复

实际持有人cash/shares用于财富指数收益；新增reference_cash/reference_shares只用于检查除权参考价，不能拿虚拟权益替代投资者获得的实际权益。只有附有已核对来源的事件才接受该覆盖；不得从价格倒推分红。未提供特殊参考字段时保持原算法，不放宽1.1分容差。

同日分派合并与公告更正是不同语义；本次均使用逐项核对的实施公告总额统一记录，然后去重。没有将任意同日记录相加，也没有用浮点容差吞掉金额冲突。转增的现金/股数错误仅在预期原值组合匹配时纠正。
