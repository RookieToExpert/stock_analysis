# 默认评分总回报接入与数据验收（2026-11-16，北京时间）

本目录记录 v0.3.3、计算修订 `2026-11-16-r4`。主目录 main 的下载及定时服务未变更。

## 已落实

- 默认 `score.fetch` 优先只读本地 Baostock 不复权日线，用东方财富已实施分红补充公司行动；按除息日收盘价再投资构建税前研究指数。不是实际到账、扣税费的可交易收益。
- 与上证综指、深证成指日期交叉校验，要求整个窗口逐交易日完整。月波动用37个完整月份端点，当前回撤和区间最大回撤分别保存。
- 丢日、事件冲突、未解释除权参考价、无法解析的方案均拒绝重建。回退到前复权代理时不参与新主名单波动率排名，保留失败原因。
- 默认读取仓库 `data/pit`，独立工作目录可通过 `STOCK_ANALYSIS_PIT_DIR` 指定现有下载目录。仅文件读取，不建立第二个 Baostock 会话、不修改原始数据。
- 新筛选目录带 v0.3.3-r4 后缀；manifest 拒绝跨日期、跨修订及无版本旧输出混合续跑。旧 v0.3.2 快照仍走冻结计算器。

## 官方全收益基准

`H00300`（沪深300全收益）、`H00922`（中证红利全收益）从中证指数官方接口取得，原始响应及来源URL均保存。代码身份参考官方 [沪深300说明](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/000300factsheet.pdf) 与 [中证红利说明](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/000922factsheet.pdf)。

`benchmark-calendar.json.gz` 为两个指数逐年取得的原始日历，两者日期集合一致。2017-05-02至2026-10-30两个基准各2307个交易日完整；`benchmark-summary.json` 记录过滤范围。原响应含2017-05-01、2018-06-18非交易日记录，且缺2026-11-12；不补值、不声称11月窗口完整。标准化代码按独立日历严格拒绝缺交易日，保留区间外及非交易日排除记录。

## 资格过滤后的覆盖诊断

`eligibility-detail.json.gz` 保存逐评价日、逐公司的原因；summary给出计数。先查上市满五年和当日非ST，再查连续五年年报字段。行业与市值过滤尚未认证，所以这仍不是正式策略门槛。

2026-09-01的5212家公司中：643家因年限或ST排除，1892家资格未知，2677家已确认满足这两项资格；其中1190家年度财务输入不全（44.45%）。下载进行中，此结果是审计时读取状态，不代表下载最终结果。不能把未知丢掉后声称全池覆盖合格，也不能把缺失 CFOToNP 当0。

复查：`python3 model/eligibility_audit.py DATA_DIR OUTPUT_JSON`。仅写指定输出。

## 剩余工作与门槛

- 下载完成后重新确认完整股票池、行业、市值及年度财务覆盖；空字段可能仍需原始历史披露来源，不能用今天重述值无标记回填。
- v1.1要求的20家公司（含5家退市）财务/分红/公告日期审计及30项ST实施撤销公告抽查尚未完成；原始财报版本可得性尚未认证。
- 受限资金、永续工具、非现金稀释的全市场证据仍缺，新评分保持未知、不先给相关7+5分；没有伪造人工核验记录。
- 周期保护仅完成预登记的样本内影响实验，样本外策略验证未完成。不会用当前数据质量下的收益曲线宣称有效。

因此不发布正式策略收益回测，也不将 Issue #7 整体标记完成。代码可修复部分与数据验证进度分别记录。
