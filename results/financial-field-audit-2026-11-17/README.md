# 缺失现金流字段的发行人原文核验

cash-review.json 覆盖原固定 20 个样本：14 个供应商已有 CFO/NP 比率与原报告直接现金流/净利润之比在六位小数精度内一致；6 个缺比率以报告中的合并经营现金流净额补证。不得把空白比率填零，也不反推比率写入供应商数据。

6 个直接金额（元）：600355/2024 -12,684,515.96；600086/2022 -105,104.84；600687/2020 -16,983,444.42；600608/2024 9,179,255.99；603773/2024 126,963,270.85；688327/2024 -307,051,752.30。刚泰概览表跨行易错，采用完整合并现金流量表及附注对应本年数。

原样本中的东方金钰 2022、刚泰 2020 报告晚于退市日，因此这两项金额核对仅是字段证据，不构成上市期回测认证。上市期替代样本见 financial-vintages-2026-11-17/listing-valid-review.json。

调用要求证券、报告期、供应商原始净利润、原始公告日期均一致，来源正文哈希一致且严格早于使用日；供应商后来补有比率时不覆盖。missing-cash-inputs.json 为六个冻结最小输入，实际离线测试验证日期边界、版本变化、重复记录和原始数据不变性。
