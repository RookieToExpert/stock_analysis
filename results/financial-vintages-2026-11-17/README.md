# 原始年报证据归档

20 个固定样本的五年窗口共 100 个公司年度；公告索引找到并归档 87 份报告，正文及原文哈希保留。`provider-comparison.json` 的 87 项数字/日期匹配仅表示供应商净利润数字在相应报告中出现、公告日期匹配，不能由此认证全部字段、未重述性、报表口径或报告完整性。13 项未被当前索引找到，不能推断报告不存在。

`listing-sample-inputs.json` 冻结最小供应商输入及原抽样上限，`listing-valid-review.json` 可用 `model/review_listed_sample.py` 离线重放。东方金钰、刚泰原抽样选到退市后公告，现改用 2019 年报。两份报告均写明董事会拟不分配利润；这仅是预案，不能冒充最终实施的分红证据。安记食品报告使用前轮巨潮归档作为补充来源。

`collect_financial_vintages.py` 保存完整索引候选及更正/修订记录；最早被索引版本不自动等同已认证原始版本。首次采集的索引与候选作为审计记录保留。
