# r9：独立于行情下载的历史证据与时点审计

本轮只在 `stock_analysis-codex` 工作，主下载目录只读，未启动 Baostock 会话。

## 已接入的修复

- 官方历史行业：27 期、111,813 条证券/报告期记录。2016Q4–2021Q3 证监会表和 2023H1–2026H1 中上协表按**真实发布日期严格早于调仓日**使用。2023H1 表直到 2024-02-08 才发布，不能回填 2023 年。保留两个分类标准及表龄；没有新发布表时仅代表“最新已发布分类”，不证明期间没有行业变化。2017Q1 原表把石大胜华和科森科技写成同一代码 603026，标歧义，不猜测修正。
- ST：461 个真实撤销风险警示/恢复正常上市事件已绑定当时公告及正文哈希，其中 447 个按严格正文模板提取、14 个逐项阅读确认。终止上市、摘星但仍 ST、只有申请公告均不放行。
- 现金流：20 个固定样本逐项复核，14 个已有 CFO/NP 与原报告匹配；6 个缺比率用合并现金流量表直接金额补证，不反推伪造比率，不覆盖原始文件。这个检查只解除对应字段缺失，不认证整份财报。
- 沪科 2024 年净现金：其他流动负债中的关联方借款至少 60,522,500 元，已经超过全部账面货币资金上界 27,191,426.46 元，因此可确定不满足净现金；不声称已完整枚举债务。
- 沪科 2020–2024 年母公司融资：5 份年报逐年核验股本、证券发行、股份支付及母公司吸收投资现金流，覆盖该固定窗口。不能套用到 2021–2025。
- 历史市值：实现 v1.1 的“前一可见原始收盘价 × 最新已公布报告期总股本”代理值；按报告期选最新，不能让后来发布的年报覆盖已经公开的一季报。它不是经过公司行动逐日核对的有效股本，不用于正式硬过滤。
- 抽样：剔除东方金钰、刚泰退市后发布的报告，改选 2019 年上市期间报告。冻结最小原始输入并提供离线重放脚本；20 个重选报告的净利润数字和发布日期可核对，但这不等于所有字段/版本认证。
- 采集缓存：来源 URL、正文哈希及最小可读长度均校验；网站短错误页不能标成成功。`st-source-audit-2026-11-17/unusable-sources.json` 明列旧归档中的不可用源。

## 结果边界

`eligibility.json.gz` 和 `summary.json` 为当时正在下载目录的只读诊断，**不是原子冻结全市场快照，也不是收益回测**。2026-09-01 截面：2,467 只通过已知上市年限/ST/行业检查，其中 967 只仍有年报字段缺失；另有 1,657 只文件缺失/无效、326 只缺摘帽证据。该数字不能用于宣称全池通过率或将变化归因于本次代码。

新增公告检索覆盖 463 个去重事件，453 个补证、9 个确认为退市相关公告不放行、1 个海源复材日期矛盾继续未知。`eligibility-final.json.gz` 为补证后的新诊断，2026-09-01 截面的 ST 未核验由 326 降为 1，其余 1,654 个未知来自缺文件/无效文件；具体见 final-summary.json；目录下载仍在变化，前后总体数量不能全部归因于补证。全市场原始财报版本、完整现金债务附注和五年融资、真实有效股本、缺失公告仍需证据；不能说“只剩行情下载”。`strategy_gate_pass` 仍为 false，`total_return_verified` 没有放开。
