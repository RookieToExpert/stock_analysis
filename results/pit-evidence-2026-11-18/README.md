在独立的 `stock_analysis-codex` 目录运行以下命令。程序读取已下载文件，终端显示该调仓日各类问题的股票数，CSV 列出需要查公告的股票、日期和字段。

```sh

```

去掉 `--day 2026-09-01` 可检查全部调仓日。要保存含资格未知原因、缺文件代码的完整结果，可在数据目录之后加输出路径，例如 `/tmp/pit-audit.json`。下载增加后重新运行即可看到新股票。

| CSV 中的记录 | 怎么查 |
| --- | --- |
| 财报 / cash / CFOToNP | 到巨潮资讯搜证券代码及对应年度的原始年报全文。打开合并现金流量表，核对单位、本期的“经营活动产生的现金流量净额”、报告期和公告日。这个比率空白时，可用经核实的直接金额。 |
| 财报 / 其他字段或 rows=0 | 按 CSV 中的报告期和表名核对当时已经公开的财报。`rows=0` 表示截至评价日前，该表没有符合日期要求的记录。 |
| 摘帽公告 / daily / isST | 在“标志变化日”前后查发行人正式披露的“撤销风险警示”公告，核对代码、生效日和变更后的证券简称。申请公告只能证明提出了申请。 |

可以从[巨潮资讯披露入口](https://www.cninfo.com.cn/)查询原文。财务补证保存在 [verified_financials.json](../../model/verified_financials.json)，摘帽证据保存在 [verified_st_releases.json](../../model/verified_st_releases.json)。
